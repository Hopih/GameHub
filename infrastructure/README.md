# Qdrant, эмбеддинги и реранжирование GameHub

Из корня репозитория запустите сервисы и дождитесь их готовности.

```powershell
docker compose up -d --wait --wait-timeout 720
```

Qdrant доступен на `http://127.0.0.1:6333`, модель на `http://127.0.0.1:18081`. Порты на хосте можно изменить через `QDRANT_PORT` и `EMBEDDINGS_PORT`. При первом запуске сервис скачивает веса модели. Данные Qdrant и кэш весов сохраняются в именованных томах при пересоздании контейнеров.

Реранкер `mmarco-mMiniLMv2-L12-H384-v1` доступен на `http://127.0.0.1:18083`, его порт задаёт `RERANKER_PORT`. Веса модели сохраняются в томе `reranker_cache`.

## Индекс игр

Запустите импорт из корня репозитория после запуска Qdrant и модели. Ключ RAWG берётся из `RAWG_API_KEY` или `RawgApiKey` в `appsettings.Local.json`.

```powershell
dotnet run --project src/GameHub.Server -- --import-games
```

Импорт отбирает 10 000 выпущенных игр, учитывает рейтинги и число оценок, распределяет часть мест между жанрами и годами выпуска. Для выбранных игр он загружает описания из RAWG и записывает векторы и данные карточек в отдельную коллекцию Qdrant. Готовая коллекция подключается автоматически. Повтор команды продолжает прерванный импорт по списку из `.local/game-index` и пропускает игры, которые уже сохранены в Qdrant.

За одно полное заполнение понадобится около 10 000 запросов за описаниями и несколько сотен запросов за списками. Для пробного запуска можно добавить число, например `--import-games 64`. Пробная коллекция сохраняется отдельно, а поиск переключается на индекс только после полной загрузки 10 000 игр.

## Поиск по описанию

Запустите `GameHub.Server` и откройте «Для тебя». Форма отправляет описание в `POST /games/recommendations`. Сервер преобразует полное описание в вектор и ищет похожие игры в готовой коллекции. Пока коллекция готовится, а также когда в ней нет близких совпадений, сервер использует [описания тегов](../src/GameHub.Server/Infrastructure/RecommendationTags.json) для подбора игр из RAWG.

Реранкер оценивает полный запрос вместе с описанием и метаданными каждого из первых 30 кандидатов. Сервер объединяет позиции и показывает до 12 игр. Векторный поиск получает больший вес, чтобы сохранить сильные исходные совпадения. Для уже проиндексированных игр текст загружается из RAWG при первом использовании и сохраняется в Qdrant. Новый импорт сохраняет текст сразу. Когда реранкер или описания временно недоступны, сервер возвращает исходную векторную выдачу. Чтобы отключить реранкер, задайте `GAMEHUB_RERANKER_ENABLED=false` перед запуском GameHub.

[Расширенный словарь](../src/GameHub.Server/Infrastructure/RawgRecommendationTags.json) содержит метки RAWG и их русские названия там, где удалось получить перевод. Сервер строит для него отдельный индекс в фоне при первом поиске. Пока индекс загружается, выдача использует ручной словарь. Когда индекс готов, расширенные метки помогают при совпадении названия или синонима либо при отсутствии близких меток в ручном словаре.

Если порты Docker изменены, задайте серверу локальные адреса через `GAMEHUB_EMBEDDINGS_URL`, `GAMEHUB_QDRANT_URL` и `GAMEHUB_RERANKER_URL`.

Отправляйте описания игр и запросы игроков на один `POST /embed`. Добавляйте к описаниям `passage: `, а к запросам `query: `, в том числе для русского текста. Сервис обрезает входной текст до 512 токенов и возвращает нормализованные векторы по 384 числа. Для коллекции Qdrant используйте `size: 384` и `distance: Cosine`. [Карточка модели](https://huggingface.co/intfloat/multilingual-e5-small)

```powershell
$body = @{
    inputs = @(
        'passage: Explore a medieval open world and fight monsters.'
        'query: игра про охоту на монстров в средневековом открытом мире'
    )
} | ConvertTo-Json

$vectors = Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:18081/embed' `
    -ContentType 'application/json; charset=utf-8' -Body ([Text.Encoding]::UTF8.GetBytes($body))
$vectors[0].Count
$vectors[1].Count
```
